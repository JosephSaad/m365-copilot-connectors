7.5BLOCKING

Is a ConnectorState database available, and who owns it?

Four things need it: incremental reads, the single-instance run lock, run history, and BOTH reconciliation scripts. Without it the connector reads in full every run and cannot be reconciled at all - an empty inventory is not evidence the index is empty.

7.6OPERATIONAL

SQL Server — source-specific

S.1BLOCKING

Is Row-Level Security applied to the table or view?

STOPS NOTHING IN CODE. Four connectors refuse a source that enforces per user; the SQL one does not, so this answer is the only control. SELECT * FROM sys.security_predicates

S.2BLOCKING

Is Dynamic Data Masking applied to any column?

Also unguarded. SELECT * FROM sys.masked_columns WHERE object_id = OBJECT_ID('<VIEW>')

S.3BLOCKING

Are any columns Always Encrypted?

Also unguarded, and it fails silently: Always Encrypted columns index as ciphertext, which no dashboard can tell from text.

S.4BLOCKING

Which view is authoritative, and can the push identity read views only?

SQL-7: the crawl identity should not be able to read the base tables.

S.5BLOCKING

Authentication: Entra token, Windows integrated, or SQL login from the vault?

SQL-1 preference order. A SQL login needs a Key Vault secret.

S.6BLOCKING

Is there a modification timestamp, and does it cascade from children to parents?

sql/26 installs the cascading triggers. Without them incremental misses hierarchy edits.

S.7BLOCKING

Which column is the soft-delete flag?

SQL-8: the filter must not be bypassable by editing the tool.

S.8OPERATIONAL

Is Encrypt=true available with a trusted certificate?

SQL-3: TrustServerCertificate=true is rejected in Production.

S.9OPERATIONAL

What proportion of rows may legitimately disappear between crawls?

Sets Settings:MaxDeletePercent. Default 10 is a guess until someone chooses.

CDP — Hive, HDFS, Atlas — source-specific

C.1BLOCKING

Which of the three connectors are in scope: Hive contracts, HDFS documents, Atlas catalogue?

Section 0 of CDP-PILOT-PARAMETERS. Decides whether one, two or three are built.

C.2BLOCKING

Are Ranger security zones in use?

STOPS THE RUN. Exit 4, RefuseSecurityZones, control CDP-17.

C.3BLOCKING

Are tag-based policies configured on cm_tag, and is Tagsync running against Atlas?

STOPS THE RUN if any tag policy denies or masks: exit 4, control CDP-19. A tag policy that only grants is ignored. Settings:RangerTagService defaults to cm_tag.

C.4BLOCKING

Do any read-carrying policies have allowExceptions or denyExceptions?

STOPS THE RUN for allowExceptions. denyExceptions are evaluated and logged, not refused. Control CDP-18.

C.5BLOCKING

Do any policies grant to named users rather than groups?

RoutingEvaluator reads item.Groups and never item.Users, so user grants are dropped.

C.6BLOCKING

Do any policies carry validitySchedules or item conditions?

STOPS THE RUN. A condition or validity schedule has no representation in a Graph permission, which is a static snapshot with no clock. Control CDP-18.

C.7BLOCKING

Do any in-scope Hive tables carry a row filter or column mask?

STOPS THE RUN for that table: controls CDP-1 and CDP-2.

C.8BLOCKING

What are the exact Ranger service names?

cm_hive and cm_hdfs are assumptions until confirmed; cm_tag is service 2.

C.9BLOCKING

Are in-scope columns tokenized at rest, or masked by Ranger?

Opposite outcomes: a mask means we skip the table, at-rest means we index tokens.

C.10BLOCKING

Is the data in an HDFS encryption zone, and does the account need a KMS key ACL?

KMS appears in the tag policy permission set.

C.11OPERATIONAL

Kerberos realm, keytab location, rotation owner, and the gMSA if one is used?

aes256 is mandatory after the cipher change.

C.12OPERATIONAL

Ranger Admin URL and TLS port, and is a firewall opening needed?

Longest lead time on the CDP path.

C.13BLOCKING

Which cluster and which data domain, and is QA or UAT the pilot environment?

ACZ has a footprint on more than one cluster.

Oracle — source-specific

O.1BLOCKING

Is there a VPD policy on the view?

STOPS THE RUN. SELECT * FROM ALL_POLICIES WHERE OBJECT_NAME = '<VIEW>'

O.2BLOCKING

Is Oracle Label Security in use?

STOPS THE RUN. SELECT * FROM ALL_SA_TABLE_POLICIES WHERE TABLE_NAME = '<VIEW>'

O.3BLOCKING

Is Data Redaction applied?

STOPS THE RUN. SELECT * FROM REDACTION_POLICIES WHERE OBJECT_NAME = '<VIEW>'

O.4BLOCKING

Is Real Application Security in use?

SELECT COUNT(*) FROM DBA_XS_SECURITY_CLASSES

O.5BLOCKING

Do Oracle roles map to directory principals (EUS or Kerberos)?

If not, grants are unrepresentable in a Graph ACL and there is no connector to build.

O.6BLOCKING

Which roles hold SELECT, and their Entra equivalents?

SELECT * FROM ALL_TAB_PRIVS WHERE TABLE_NAME = '<VIEW>'

O.7BLOCKING

Which column is the modification timestamp?

Drives incremental reads, which are implemented. The column must be UTC, monotonic and move on EVERY change. ORA_ROWSCN does not qualify: block-level without ROWDEPENDENCIES.

O.8OPERATIONAL

Easy Connect string or TNS alias? Is a wallet in play?

Oracle has no Server-plus-Database pair.

O.9SIZING

Database version 12c or later?

The reader emits FETCH FIRST, which 11g lacks.

O.10OPERATIONAL

Which column carries classifications, if sensitivity labels are wanted?

The connector reads a CLASSIFICATIONS column, comma-separated. The label property is registered in the schema whether or not you use it, because a registered schema is append-only.

MongoDB — source-specific

M.1BLOCKING

Which collections, and is access granted at collection granularity?

No document-level security in the engine.

M.2BLOCKING

Is the source a view using $redact or $$USER_ROLES?

STOPS THE RUN. Views are refused as a class: the driver cannot tell one that redacts on $$USER_ROLES from a plain one.

M.3BLOCKING

Are any fields under CSFLE or Queryable Encryption? Name them.

STOPS THE RUN on the document carrying it. Ciphertext indexes silently and is useless.

M.4BLOCKING

What is the declared projection — field to property?

Cannot be inferred; an inferred schema changes when a document does.

M.5BLOCKING

Does every document carry an updatedAt?

Decides whether incremental is possible AT ALL. _id encodes creation time, not modification. Without updatedAt every crawl is full, and change streams do not satisfy the checkpoint contract.

M.6BLOCKING

Which roles grant read, and their Entra equivalents?

db.getRoles({showPrivileges: true})

M.7BLOCKING

Are documents deleted outright, or flagged?

A hard delete needs a full-crawl inventory diff.

M.8OPERATIONAL

Replica set or sharded? Read-preference requirement?

The crawl reads SecondaryPreferred.

M.9SIZING

Is the source a GridFS bucket rather than a document collection?

Detected, not configured - a bucket is the pair <name>.files and <name>.chunks. In bucket mode each file's text is extracted (PDF, OpenXML, plain text) and items are typed File. Reading a bucket as an ordinary collection would index its metadata documents instead, which looks like a working crawl.

M.10OPERATIONAL

Which field carries classifications, if sensitivity labels are wanted?

The connector reads a classifications field, an array or a comma-separated string.

STOPS THE RUN. Same view, same refusal.

Which tables are text rather than measures?

The scoping question for a warehouse: an index cannot compute a sum.

T.5BLOCKING

Drives incremental reads, which are implemented. Without one the connector reads in full every run, which is safe but slower.

T.6BLOCKING

Can the crawl identity read DBC.ColumnsV and DBC.SecConstraintsV?

Without both grants the security guard cannot run, and the connector fails CLOSED rather than reading on.

T.7SIZING

Indexing a copy indexes yesterday's answer.

T.8OPERATIONAL

Is there a query band or workload rule a crawl must set?

A long read can land in the wrong workload class.

T.9OPERATIONAL

Which column carries classifications, if sensitivity labels are wanted?

Same CLASSIFICATIONS contract as Oracle.
